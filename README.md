# Titanic EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## Objectives
- Analyze passenger survival rates.
- Explore passenger age and gender.
- Study passenger class and fare.
- Identify missing values.
- Visualize relationships between variables.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The Titanic dataset contains information about 891 passengers.

## Key Findings
- Total Passengers: 891
- Survived: 342
- Not Survived: 549
- Average Age: 29.7 years

## Project Files
- Titanic_EDA.ipynb
- Titanic_EDA.html

## How to Run
1. Download the repository.
2. Install required libraries.
3. Open Titanic_EDA.ipynb in Jupyter Notebook.
4. Run all cells.

## Conclusion
This project helps understand passenger survival patterns through data analysis and visualization.
